# MuscleMory

トレーニングの記録を、次のトレーニングにつなげるためのFlutterアプリです。

## 現在できること

- 重量・回数を入力し、完了したセットだけを記録
- 2.5kg刻みなど小数を含む重量の入力・保存
- セットの追加・削除と、最低1種目を残した任意の種目削除
- 誤って削除したセットや種目を入力内容ごと元に戻す
- ベンチプレス、ダンベル種目、背中、脚、肩、腕の種目選択
- 前回記録との比較
- 複数種目を1回のトレーニングとして保存
- 履歴タブから直接開く月間カレンダーとトレーニング詳細
- 記録日と月間の回数・セット数・総ボリュームが分かる月間カレンダー
- 履歴の修正・削除と、同じメニューの再実行
- ホームから最近のメニューをすぐ始めるクイックスタート
- ホームの前回トレーニングから履歴詳細を直接表示
- よく使う内容を名前付きで保存し、ホームから始められるマイメニュー
- 誤って削除したマイメニューを元に戻す
- 週間回数、総ボリューム、種目ごとの自己ベストの集計
- 週ごとの目標進捗と、目標を達成した連続週数
- 種目別の最高重量・推定1RM・成長グラフ
- トレーニング完了時の自己ベスト更新通知
- 直近7日間の部位別セット数
- 主要20種目の検索と、次回も再利用できるカスタム種目作成
- 必要な人だけ有効にできる休憩タイマー（30秒〜3分）
- トレーニングのコンディションメモ
- 入力途中のトレーニングを自動保存して再開
- ホームで入力途中の内容を確認し、再開または破棄して新規開始
- クイックスタート、マイメニュー、履歴からの再実行でも入力途中の内容を保護し、今日の記録として開始
- 履歴の修正や戻る操作をしても、新規トレーニングの下書きを保護
- 種目・部位・場所・メモから履歴を検索
- トレーニング場所と経過時間の記録
- 今日または過去の日付を選んで記録し、履歴修正時にも日付を変更
- 過去日の追加後も日付順を保ち、履歴カードで場所とメモを確認
- 一覧にないジムや体育館などの場所を自由入力
- iPhone内へのローカル保存
- 保存データの一部が不正でも、有効な履歴を読み込んで起動
- マイメニューやカスタム種目も、有効な項目を失わず安全に復元
- Supabaseの接続・アカウント・クラウド同期の土台
- JSONファイルまたはクリップボードを使った記録・マイメニュー・設定のバックアップと復元

## 起動方法

1. VS Codeでこのフォルダーを開く
2. 画面右下の実行先を `iPhone 17` にする
3. `F5` を押す

ターミナルから確認する場合:

```sh
/Users/macintosh/Documents/development/flutter/bin/flutter pub get
/Users/macintosh/Documents/development/flutter/bin/flutter analyze
```

## データ保存

通常は `shared_preferences` にJSONとして保存します。アプリを再起動しても記録とトレーニング場所は残ります。Supabaseを設定してログインすると、ローカル保存を続けながらクラウドへ送信し、ほかの端末の記録も取り込んで統合します。

## Supabaseを接続する

1. Supabaseでプロジェクトを作る
2. DashboardのSQL Editorで `supabase/schema.sql` を実行する
3. `supabase.example.json` を複製して `supabase.json` にし、Project URLとPublishable keyを入れる
4. VS Codeの「実行とデバッグ」で `MuscleMemory（Supabase同期）` を選んで起動する

ターミナルから起動する場合:

```sh
/Users/macintosh/Documents/development/flutter/bin/flutter run \
  --dart-define-from-file=supabase.json
```

`supabase.json` はGitの保存対象から外しています。Secret keyやservice_role keyはアプリに入れないでください。

## 開発環境の注意

このMacでは `flutter analyze` と `flutter test` が成功しています。シミュレーター確認は、画面構成を大きく変更した節目で行います。
