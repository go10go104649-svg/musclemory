# SETKEEP 現行確定仕様

更新日: 2026-09-26

このファイルを、SETKEEP / SETKEEP TRAINER の現行仕様を確認する際の正本とする。日付付きの `docs/qa/` はその時点の検証証跡であり、現行仕様と異なる数値や一時状態がある場合は本書を優先する。実装済みかどうかは、各項目の状態を別に確認する。

## ブランド

- SETKEEPの正式カラーは `#C7F36B`。
- `#00D084`、`#04D497` などの旧カラーは正式色として使用しない。
- SETKEEP TRAINERはファミリー内のアプリ固有アクセントとして現行mainの `#38C6FF` を使用する。これはSETKEEP本体の正式カラーを置き換えるものではない。

## SETKEEP BUSINESS / SETKEEP TRAINER のB2B料金

- 月額 **3,980円**。
- **5IDまで含む**。
- 6ID目以降は、1IDあたり月額 **500円追加**。
- 見積式は `3,980 + max(有効ID数 - 5, 0) × 500` 円/月。
- 旧仕様の「4,980円／店舗・トレーナー無制限」は廃止し、正式仕様として使用しない。
- 料金仕様は確定しているが、Stripe Checkout・検証済みWebhook・実請求の接続は未完了であり、実課金済みとは扱わない。

## SETKEEP TRAINER 右上ベル

SETKEEP TRAINERの右上ベルは、トレーナーからのメニューコメント等の新着通知を表示する。未読がある場合は未読数をバッジ表示する。通知ベルと未読数表示を含む一連の体験を仕様とし、単なるメニュー／コメント一覧の手動再読み込みだけでは実装済みと扱わない。

現行mainにはメニュー／コメントの一覧表示と再読み込みはあるが、右上ベルと未読数バッジは未完了である。

## Android休憩タイマー

### 目標仕様

- ロック画面・通知領域で残り時間を大きく見せる。
- タイマー終了後に通知から「セット完了」を操作できる。
- 次の種目がある場合は、セット完了後に次の休憩タイマーへつなぐ。

### 現行判定

Androidの通知・PendingIntent・セット保存に関するテストや実装は存在するが、Galaxy実機では停止ボタンを押すとポップアップが消え、画面を開かないと続行できない不具合／未完了点が残っている。したがって、ロック画面からの停止・続行・次タイマー遷移を含むAndroid休憩タイマーは、現時点で実装済みとは扱わない。

## リポジトリmainとの整合性メモ

2026-09-26に最新 `origin/main` を確認した。仕様更新は文書に限定しており、3Dアセットやカタログを自動昇格していない。現行mainの `tool/exercise_forms/catalog.json` は `verified 14 / authored 34 / planned 164` で、上記の最新確定進捗（通常公開18種）と差がある。18種の公開数を実装状態へ反映する場合は、カタログ・生成ファイル・両OS通常導線QAを別途そろえてから行う。
