# 部位タブ3D人体 修正・実画面確認（2026-09-14）

承認済みベンチプレスと同じMPFB2人体制作ベースを使用し、部位確認専用のニュートラル立位GLBへ置換。旧51個の楕円体モデルは参照とFlutter配布対象から除外しました。既存の黒いカードと期間切替UIを維持しています。

- 約1.85MB、アニメーション・器具・スキンなし。元の連続メッシュを15筋肉領域＋ニュートラル領域に分け、境界座標と滑らかな法線を保持。
- 前面・側面・背面は同じGLBの固定カメラ切替。期間変更でも方向を維持し、素材色のみ更新。
- 既存MuscleRegion集計に割当。ゼロ値を明示的にグレーへ戻すため、前期間の赤が残らない。
- CC0記録と編集用Blenderデータを art/body_tab に保存。再生成スクリプトは tool/body_tab/export_body.py。

## 検証結果

- flutter analyze: No issues found.
- flutter test: 66 tests passed（部位資産の網羅性、期間変更時の方向保持を追加）。
- flutter build ios --simulator --target lib/main.dart: 成功。iPhone 17 / iOS 26.5 Simulatorへインストール済み。
- Android :interactive_3d:compileDebugKotlin: 成功。Android実画面は未検証。
- Simulatorで3方向を操作し、初回表示の傾き・頭や足の切れ・ベージュ部品がないことを確認。
- 実記録: 1週間34セット、1ヶ月50セット、3ヶ月50セット、6ヶ月50セット、1年50セット。保存記録から計算した集計と一致。週→月で胸11→12セット、脚3→15セットなどが変化し、人体の濃淡も更新。
- 保存データを読み書きしないQA専用起動（tool/body_tab/qa_main.dart）: 0→2→6→9→14セットを5期間で確認。胸・背中・脚・腹と補助筋への着色、未トレーニング部位のグレーを確認。1年から1週間に戻して赤が消えることも実画面確認。
- 履歴カレンダー・トレーニング詳細・体重表示・SNS画像プレビューを確認。共有送信は行っていません。記録・下書き・体重などの既存回帰テストも通過。
- QA後は通常版へ復帰し、元の34セットの部位タブを再確認。

人体領域はトレーニング対象の説明用マスクです。個人の筋活動実測ではありません。性能は資産サイズと無アニメーション・停止時再描画方式で確認し、実機ベンチマークは未実施です。
