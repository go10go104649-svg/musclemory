# トレーニング時間・休憩通知の検証（2026-09-14）

## 実装

- 最後のセット／記録を削除した際に時間を停止・確定。
- 停止済み下書きは保存済みの秒数を保ち、勝手に再開しない。
- 下書きの保存を直列化し、完了・削除後の遅延保存による復活を防止。
- 中断時は保存完了を待ち、明示的な再開では中断中の時間を加算しない。
- iOSの遅れた通知許可・追加コールバックから古い通知が復活しないよう修正。
- 終了時刻を共有し、残り秒数の切り捨てによる早い終了を防止。
- Androidで予約と表示済み休憩通知をキャンセル。
- 未表示の部位タブのネイティブ3Dビューを破棄し、画角選択は保持。
