# MUSCLEMORY 部位タブ：筋肉輪郭と相対比率の修正

2026-09-14 / iPhone 17, iOS 26.5 Simulator

## 完成した内容

承認済みMPFB2人体から作った自然な立位を維持し、1つの連続メッシュ上に15筋肉の材質マスクを配置しました。赤い別立体や旧楕円体モデルは使用していません。大胸筋・三角筋前部／後部・二頭筋・三頭筋・前腕・広背筋・僧帽筋・腹直筋・腹斜筋・大臀筋・四頭筋・ハム・内転筋・ふくらはぎを個別に扱えます。腹直筋は左右4段、脚と背中は筋腹に沿う曲線輪郭です。境界のみ細分化し、元メッシュの粗い輪郭を改善しました。解剖学の説明用に簡略化したマスクです。三角筋中部は独立マスクにせず前部／後部で肩を覆っています。

GLBは1ノード・1メッシュ・16材質（筋肉15＋グレー領域）、約3.7MB、73,220頂点・146,436三角形。器具・アニメーション・スキニングなし。同じモデルを固定カメラ3方向から表示し、期間変更でもカメラ方向を保持します。Blender編集元とCC0記録も保存しています。

iOS読込ライブラリが材質名を捨てるため、対象GLBのプリミティブ順序と材質メタデータから名前を復元しました。材質色変更は対象人体に限定しています。Androidにも材質単位の更新を追加しました。

色強度は、表示数値と同じ部位別セット数を選択期間の最多部位で割った比率です。既存の種目別主働筋／補助筋スコアとは分離し、カテゴリから複数筋肉へ同じ比率を展開します。0セットはグレー、最多は濃赤、その他は比率に応じた薄赤。3D照明で低比率が白く飛ばないよう一定の明るさ補正を施し、セット数の絶対量は補正に使いません。
