# MUSCLEMORY 指定7項目 QA（2026-09-15）

## 対応内容

1. 体重推移をホームだけに表示し、履歴の月間カレンダーから削除。
2. SNS用画像から総ボリューム・トレーニング時間と両トグルを削除。種目別の記録表示と背景写真選択は維持。
3. トレーニング設定を「セット完了チェック → 休憩タイマー → 休憩時間 → トレーニング時間」の順に整理。親設定OFF時は休憩設定を非表示。
4. 休憩終了時の画面表示に加え、Android/iOSのネイティブ通知音・振動を追加。バックグラウンド通知にも既定音を設定。
5. 場所管理を「いつもの場所」画面へ一本化。選択・追加・名称変更・削除を同じ画面に配置し、既存保存データは維持。
6. バックアップ画面を「バックアップを書き出す」「バックアップから復元」の2項目に整理。形式検証と復元確認を追加。
7. マイページにお問い合わせフォームを追加。不具合報告・機能要望・その他、件名、本文、任意画像、アプリ/OS/端末情報に対応。

## 未確認・判断事項

- 実Android端末と実iPhoneでの通知音量・振動は、端末のサイレントモードと通知設定に依存するため未確認。
- お問い合わせ受付先は未指定。現在は端末の共有画面からメール等へ渡す方式。固定の送信先や自動送信には、受付メールアドレスまたはバックエンド方針が必要。
- ネイティブのファイル選択UIで実ファイルを選ぶ操作は今回自動化していない。JSON形式検証、非対応形式の拒否、復元前確認、既存の読み込み処理はテスト済み。
